- `bash scripts/setup.sh` installs dependencies and creates a Kirby Starterkit playground in `.playground/` with this plugin linked. Panel credentials are in `.playground/.panel-credentials`. The `/logos` page renders the `logo-soup` snippet with and without `cropToContent` for the test fixtures, an opaque PNG, and the Starterkit icons.
- `pnpm playground` serves it at `http://localhost:8000` (`pnpm playground:portless` for a Portless URL, see `pnpm exec portless list`).
- `vendor/` is committed and holds production files only: install development dependencies with `COMPOSER_VENDOR_DIR=.repos/vendor composer install`, never with plain `composer install`. Run Composer scripts the same way, e.g. `COMPOSER_VENDOR_DIR=.repos/vendor composer run analyze`.
- Mago formats, lints, and analyzes the PHP code (`fmt`, `lint`, `analyze`, `fix` Composer scripts). `stubs/kirby.php` declares Kirby magic methods for the analyzer. `composer test` runs `tests/run.php`, which needs Imagick with librsvg or Inkscape for SVG files. ImageMagick's own SVG renderer adds an edge pixel to shapes, so the SVG bounds tests fail with it.
